# AI Agents Guide

This document outlines the usage and context for AI agents (LLMs) working on this repository (`go-racer`). 

> **IMPORTANT:** This document should be kept up to date as the project evolves, new practices are adopted, or new agentic workflows are introduced.

## Purpose

The purpose of this file is to serve as a high-level guide and instruction manual for any AI coding assistants or agents interacting with the `go-racer` project. 

## Agent Instructions

- Always prioritize clean, maintainable, and well-tested Go code.
- Familiarize yourself with the project structure before making major modifications.
- Ensure that the commands or scripts you run comply with the system environment.
- When creating new features, consider the existing architecture components like terminal UI (bubbletea/lipgloss) and the plugins system.

---
*Note: Any time the project's development workflow changes significantly, please update this file to reflect the new state so future agents have accurate context.*
